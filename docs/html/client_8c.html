esp_err_t ble_mesh_client_init ( void )

Initialize the BLE Mesh client node.

Registers provisioning/config/generic callbacks, initializes the mesh stack with the local composition, and enables provisioning over ADV and GATT.

Returns
ESP_OK on success; otherwise an esp_err_t from the BLE Mesh APIs.
