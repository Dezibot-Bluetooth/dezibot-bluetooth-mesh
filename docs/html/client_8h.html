◆ ble_mesh_client_init()

esp_err_t ble_mesh_client_init ( void )

Sets up provisioning for a mesh node that contains a set of Generic Client models (OnOff, Level, etc.) and enables provisioning over ADV and GATT.

Returns
ESP_OK on success; otherwise an esp_err_t from the BLE Mesh stack.
