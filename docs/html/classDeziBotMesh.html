Detailed Description

Provides a unified interface for Bluetooth Mesh networking with flexible initialization modes (node, client-only, server-only).

bool DeziBotMesh::beginClient ( )

Initialize the node in client-only mode.

This initializes a node that can only send commands to other nodes. Useful for remote controls or sensor nodes that only publish data.

Returns
true on success, false on failure

Requires init() to have been called successfully.
