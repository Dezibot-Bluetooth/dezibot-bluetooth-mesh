Detailed Description

Common includes and types for the BLE Mesh modules.

This header provides centralized access to all required APIs for the Bluetooth Mesh implementation. It includes standard C libraries, ESP-IDF core APIs, FreeRTOS primitives, NimBLE stack headers, and BLE Mesh APIs.

Design Pattern: Central Include Pattern This reduces code duplication and ensures consistent API access across all modules. Modules only need to include this single header.
