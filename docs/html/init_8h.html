esp_err_t pre_init ( void )

Orchestrates the initialization of core system components required before application logic can run. This includes NVS flash setup and Bluetooth stack initialization.

NVS Error Handling:

  • If NVS has no free pages, flash is erased and reinitialized
  • Critical errors halt execution via ESP_ERROR_CHECK
Returns
  • ESP_OK: All initialization successful
  • Error codes from bluetooth_init() on Bluetooth failures
Note
Call this before any mesh or application operations
Fatal errors will halt execution
See also
bluetooth_init()

Initializes core system components in the correct order:

  1. NVS (Non-Volatile Storage) flash
  2. Bluetooth stack

NVS Error Handling:

  • ESP_ERR_NVS_NO_FREE_PAGES: Flash is full, erase and reinitialize
  • Other NVS errors: Halt execution via ESP_ERROR_CHECK

Bluetooth Errors:

  • Logged and returned to caller for handling
  • Application can decide whether to continue or halt
Returns
  • ESP_OK: All initialization successful
  • Error codes from bluetooth_init() on failure
Note
NVS must be initialized before Bluetooth (stores bonding info)
Fatal NVS errors halt execution
Bluetooth errors are returned for application handling
